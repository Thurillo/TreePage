🗃 Query Database

ℹ️ Come funziona

Per collegare una pagina HTML a un database MySQL, segui questi 3 passi:

Passo 1 — Crea il file credenziali (una volta per ogni DB, mai su git)

Crea il file db_configs/<nome>.yaml sul server con questo contenuto:

host: "192.168.1.10"
port: 3306
user: "utente_mysql"
password: "la_password"
database: "nome_database"

Passo 2 — Registra la query

Usa il form "+ Aggiungi query" qui sotto. Dai un nome univoco, scegli il config dal menu e scrivi la SQL.
Per i parametri usa la sintassi %(nome_param)s — il valore verrà passato dalla pagina HTML:

SELECT * FROM tabella WHERE id = %(id)s

Passo 3 — Chiama l'endpoint dal tuo HTML

Nella tua pagina projects/<nome>/index.html usa fetch():

// SELECT → GET con parametri nella query string
fetch('/api/db/nome_query?id=123')
  .then(r => r.json())
  .then(data => console.log(data.rows))

// INSERT / UPDATE / DELETE → POST con body JSON
fetch('/api/db/nome_query', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ id: 123 })
}).then(r => r.json()).then(data => console.log(data.affected))
